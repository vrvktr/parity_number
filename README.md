# Parity Number Checker

A simple React app that takes a number as input and tells whether it is even or odd.

## Features

- Clean, centered card-based UI
- Number input field
- Check button
- Results displayed as either even or odd

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Project purpose

This app is a small practice project to understand how to build a basic React application with state and conditional logic.
